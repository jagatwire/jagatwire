X Post → Image

Paste any X/Twitter post link and generate a clean shareable image instantly.

How it works (open-source + X / xAI context)

• Data is fetched live from the free community FxTwitter API (part of the open-source FxEmbed / FixTweet project – MIT licensed).
• Official X API is currently pay-per-use with no free read tier for new developers (2026). This tool avoids paid keys so anyone can use it.
• Image generation uses the open-source library html-to-image.
• Grok (by xAI) has deep native X integration. This site uses the same public post data layer that many community and research tools rely on when free official access is limited.
• Everything is dynamic — no static/hard-coded posts. Just paste a link.
